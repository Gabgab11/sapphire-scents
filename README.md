# Sapphire Scents — demo storefront

A concept website for Sapphire Scents, the Nigerian perfume house founded by Wale Jana in 2015.

- Lights-on hero: the page opens dark, the perfume glows on, then the room lights up. A different scent features on each visit.
- The Lineup: crown bottles in a receding line, driven by page scroll.
- Collections, shop by note, product quick view and a demo bag.

Plain HTML, CSS and JavaScript in `index.html`, with images in `/images`. Prices and notes come from the brand's posts; stock and delivery offers are placeholders.
